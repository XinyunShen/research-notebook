# Phase 1 — 数据→因子→检验 流水线

对应 `../design_doc.md` 第10节 Phase 1。目标不是"策略赚钱"，是把整条流水线跑通、跑对，
尤其是**因子计算的 point-in-time 对齐**（不能有前视偏差，见 design_doc.md 第2.5节）。

## 已实现

- **数据获取**（`src/data_fetch.py`）：yfinance 拉取日线行情，本地 parquet 缓存。
- **基本面数据**（`src/edgar.py`）：SEC EDGAR 官方 XBRL API，免费、权威（design_doc.md 5.2节）。
  保留每条财务数据的 `filed`（申报日期），这是避免前视偏差的关键。
- **因子计算**（`src/factors.py`），实现 design_doc.md 第4节推荐的"估值+质量+动量+
  资金流"四因子组合：
  - 动量（过去126个交易日收益率，纯价格，无对齐问题）
  - 质量（ROE，TTM净利润 / 最新股东权益，按日期横截面1%/99%分位数winsorize）
  - 价值（账面市值比 Book-to-Market，同样winsorize）
  - 资金流（Form 4 内部人净买入占流通股比例，`src/insider.py`，design_doc.md 12节
    问题15新增）
  - 质量/价值因子用 `pd.merge_asof(..., direction="backward")` 把每个交易日匹配到
    "当天为止已公开申报"的最新财报数据，杜绝用到未来数据。
  - 股东权益 <= 0 的公司（大量回购股票的科技公司常见）ROE/账面市值比没有经济意义，
    直接置空而不是硬算出 inf/-inf（见下方"踩过的坑"）。
- **验证**（`src/validate.py` + Alphalens）：对应 design_doc.md 第8节第一步（IC检验）和
  第二步（分层回测）。新增 `liquidity_mask`：用过去21个交易日成交额中位数是否
  ≥100万美元过滤"挂单没有真实成交"的股票-日（见下方"踩过的坑"）。还新增按市值
  分段的IC检验（`run_ic_by_market_cap_segment`）和 Fama-MacBeth横截面回归
  （`run_fama_macbeth`，用`linearmodels`库），把"因子效应是否随市值变化"从
  一次性诊断变成标准流程，见下方对应章节。**不包含**走步前进验证/样本外冻结
  测试/过拟合检测/交易成本（留给 Phase 3，design_doc.md 第10节）。
- **股票池**（`config/universe.py` + `config/build_universe.py`）：子池A（科技基础池，
  从 Nasdaq 官方筛选器 API 自动拉取，市值>9亿美元、美国注册，约290只）∪ 子池B
  （AI产业链主题池，对应 3.2.1节映射表，人工维护），并集305只，再减去
  `THEME_MISMATCH_EXCLUDE`（MARA/MSTR/WULF这3只比特币矿企/代理，见下方
  "组合回测"一节），**当前实际305-3=302只**，达到第8节"第零步"建议的
  300-500只门槛（此前是244只，市值门槛从20亿降到9亿）。

## 运行方法

```bash
cd phase1
source .venv/bin/activate   # 已创建好的虚拟环境；如果没有，先跑：
                             #   python3 -m venv .venv && source .venv/bin/activate
                             #   pip install -r requirements.txt

python -m config.build_universe   # 刷新科技基础池快照（建议每季度跑一次）
python -m src.pipeline            # 跑数据→因子→检验主流程
```

输出：
- `output/factor_panel.parquet` —— 完整因子面板
- `output/{factor_name}_ic_summary.csv` —— IC均值/IC信息比率
- `output/{factor_name}_quantile_returns.csv` —— 分层回测收益

## 最新一次运行结果怎么读（2026-07-22，305只股票，2016年至今，扩池+修复数据bug后）

**更新**：剔除MARA/MSTR/WULF后用302只股票重新跑了一遍全量流水线（含Form4
资金流因子），下面这些IC/Fama-MacBeth数字几乎没变（比如动量63日IC还是
0.059，ROE从0.006微调到0.010，book_to_market从-0.0005微调到-0.0001）——
这3只股票在305只里占比太小，对**横截面IC检验**这种"每天全池排序"的统计量
影响可以忽略。它们真正影响巨大的地方是"组合回测"一节里**只挑10只**的
集中持仓场景（MARA一只贡献的收益比NVDA还多），这也印证了一个道理：同一个
数据问题，对"广撒网测排序"和"集中重仓"这两种用法的杀伤力完全不是一个量级。

- **动量因子**：63日窗口 Rank IC 均值 0.059，IC_IR 0.37（比244只股票版本的
  0.056/0.33 略好），但分层收益单调性比之前弱——第1、2组顺序颠倒（不再是严格
  "分数越高收益越高"），推测是扩池带入了更多小盘、噪音大的股票，用统计功效
  （更大样本、更可信的IC）换来了一点分层干净度，是合理的代价，不是新缺陷。
- **账面市值比（价值）因子**：63日 IC 从0.008掉到接近0（-0.0005），方向也不再
  稳定为正。
- **ROE质量因子**：63日 IC 0.006，依然接近0，分层方向依然和"质量因子一般弱正
  相关"的预期相反（ROE最低组收益显著高于ROE最高组）。**这轮精修专门排查了这个
  异常**，过程中修了两个真实数据bug（DXC股数占位值、QUBT这类挂单没真实成交的
  历史数据，见下方"踩过的坑"），修复后异常方向没有变。

### 按市值分段检验（`validate.run_ic_by_market_cap_segment`，已固化为标准流程）

排查账面市值比变弱的原因时，第一次用"股票今天的市值"把整只股票粗分成"大盘/
小盘"两组，得出"新增小盘股拖累了整体"的结论——**这个诊断后来被证明不严谨**：
用"今天的市值"倒推一只股票2016年算不算大盘股，本身是一种前视偏差（很多股票
十年前市值比今天小得多）。改用**逐日真实市值**（当天股数×当天股价）重新分段，
对全部四个因子都跑，结果更可信：

| 因子 | 全池63日IC | 大盘股63日IC | 小盘股63日IC |
|---|---|---|---|
| 动量 | 0.059 | 0.052 | 0.053 |
| ROE质量 | 0.006 | **0.029** | **-0.030** |
| 账面市值比 | -0.0005 | **-0.011** | **-0.017** |

- **账面市值比在大盘、小盘两段都是负的**——不是被新增小盘股拖累，是这个因子
  在这个股票池、这段时间本身就不work，第一次的诊断结论是错的，已经改正。
- **ROE的分段结果很干净、也更有价值**：大盘股里IC=0.029（比全池强好几倍，方向
  正确，符合"质量因子在大盘蓝筹里更稳定"的传统认知），小盘股里是-0.030（方向
  反了）——"叙事驱动压过盈利质量"这个现象看起来主要集中在小盘"故事股"，不是
  普遍现象，这比"整体上ROE因子在这段样本里失效"这个笼统结论更有操作意义（比如
  未来实盘只在大盘股范围内用ROE因子）。
- **动量因子在两个市值段表现接近**（0.052 vs 0.053），是四个因子里唯一不受
  市值段影响的，进一步确认它是最稳健的信号。

### Fama-MacBeth 横截面回归（`validate.run_fama_macbeth`，市值分段的精确版）

市值分段手动分两组比较粗糙，为了更精确地回答"因子效应到底怎么随市值变化"，
给每个因子跑`未来收益 ~ 因子 + log市值 + 因子×log市值交互项`的每日横截面
回归（用`linearmodels`库的标准Fama-MacBeth实现，不是自己手写循环）。交互项
系数显著就说明"这个因子在不同市值段表现不同"是连续、系统性的规律，不是
拆两组时才出现的巧合：

| 因子 | 主效应(均值市值处) | 交互项(×log市值) | 效应转向的市值临界点 |
|---|---|---|---|
| 动量 | +0.296 (p<0.001) | -0.010 (p<0.001) | 约2.2万亿美元（现实中几乎不会翻转） |
| ROE质量 | -0.336 (p<0.001) | +0.014 (p<0.001) | 约263亿美元 |
| 账面市值比 | +0.195 (p<0.001) | -0.009 (p<0.001) | 约26亿美元 |
| 资金流(内部人) | +0.050 (p=0.97，不显著) | +0.044 (p=0.49，不显著) | 不适用 |

**比市值分段更精确的地方**：
- ROE真实临界点在263亿美元，远高于市值分段用的20亿门槛——说明市值分段测出
  的"大盘组IC=0.029"这个组里其实还混着大量效应仍为负的中型股（20亿-263亿
  美元区间），真实的ROE质量效应可能要在市值远超20亿的超大盘股里才稳定为正。
- 账面市值比的临界点（约26亿美元）非常接近20亿门槛，解释了市值分段为什么
  测出"大盘、小盘两段都是负的"——分界线正好卡在效应转折点附近，两侧都还
  没完全转正/转负。
- 动量因子临界点高达2.2万亿美元（现实中只有极少数超级巨头市值接近这个
  量级），进一步确认动量在几乎全部现实市值范围内都稳定为正，最可靠。
- 资金流因子主效应和交互项都不显著，用更严格的统计检验确认了"基本是噪音"，
  不只是IC接近0这么一个粗略印象。
- **资金流因子（Form 4内部人净买入）**：63日 IC = 0.0002，IC_IR = 0.0012，5日/21日
  IC甚至是负的（-0.0099/-0.0103），基本是噪音水平，四个因子里最弱的一个。**排查
  了原因，不是bug**：抽样检查发现P（买入）/S（卖出）交易数量比例是1089:53123，
  卖出压倒性地多——这在科技股很典型，大部分"卖出"是股权激励解锁后的常规分散化
  减持（很多还是Rule 10b5-1提前设定好的计划性卖出，不代表管理层对公司前景的
  即时判断），信息含量被严重稀释。Form 4原始XML里其实有`aff10b5One`字段能标记
  是否属于10b5-1计划，当前版本没有用这个字段过滤，是一个明确的改进方向（见下方
  "已知限制"）。另外VZ这一只股票在抓取时触发了5分钟硬性兜底（2995条filing只
  跑完2338条），是网络抖动导致的部分数据缺失，对305只股票的整体统计影响可忽略。

**再强调一次 design_doc.md 已经说过的话**：以上数字比约50只股票时的版本更接近
统计可信区间，但仍只覆盖2016年至今、没经历完整多轮牛熊周期，只能当阶段性参考，
不是"这个因子真的有效"的最终结论。

## 组合回测（`src/backtest.py`，个人小账户视角）

design_doc.md 12节：之前所有的IC/Fama-MacBeth检验，测的都是"排序准不准"，
是横截面统计量，不模拟真实持仓路径——测不出回撤、止损这类"path-dependent"
（依赖具体走过的路径，不是只看排序对不对）的东西。用户明确说了目标是个人
用小规模账户操作、**优先不亏本**、能接受提前卖出——这和"IC越高越好"
是不同的目标函数，需要真正逐日模拟持仓才能回答。

**策略设计**：只用动量因子选股（Phase 1里唯一在全部市值段都稳健为正的因子，
见上方Fama-MacBeth结果），10只等权持仓（对应小规模账户，摊得太薄会
削弱止损的意义），21个交易日（约1个月）再平衡一次。止损规则：硬止损（跌破
买入价X%卖出）和移动止损（跌破持有期最高价Y%卖出）可以独立开关或叠加，
移动止损直接对应"可以提前卖出锁定利润"这个诉求。

### 一个重要的中间发现：初版回测数字离谱到不可信

第一次跑出来的数字是**年化收益62%、最大回撤-60%**，用户当场就指出这不现实
（"巴菲特都做不到"——他大约60年年化20%，被公认是史上最好的投资记录之一）。
排查后发现有三层问题在系统性地把数字吹高：

1. **股票池混进了主题错配的公司**：MARA（比特币矿企）、MSTR（现改名Strategy
   Inc，实质是杠杆持有比特币的载体）、WULF（TeraWulf，比特币矿企）——这几只
   只是因为Nasdaq把它们分类成"Technology"板块，就被子池A捡了进来，跟"AI产业链"
   毫无关系。回测里MARA单独贡献了587%的总收益，比NVDA（197%）还多——说明
   这个高回报根本不是"策略抓住了AI故事"，是追涨杀跌的算法撞上了几个和主题
   毫不相关的暴涨暴跌股票。已经在 `config/universe.py` 的
   `THEME_MISMATCH_EXCLUDE` 里手动排除（不是穷举，之后发现新的同类错配还要
   继续补充）。
2. **股票池用"今天的市值"倒推整段历史资格**：一只股票只要现在市值够大，
   它2016年那会儿（可能还很小）也会被拿来选股——2016年的投资者不可能提前
   知道这只股票以后会长这么大。`simulate_portfolio` 新增 `min_market_cap`
   参数，用Phase 1已经算出来的逐日真实市值，只有当天真的达标才允许入选。
   **这个只解决了"用今天市值判断历史资格"这一层，不解决"AI产业链主题池
   本身是用2026年信息整理的"这一层更深的偏差**，后者是主题投资天然要
   面对的问题。
3. **完全没算交易成本**：新增 `transaction_cost` 参数（默认按单边0.1%近似
   佣金+滑点+买卖价差），不建模税（因人、因账户类型差异太大，用户需要自己
   按实际情况估算）。

### 修正后的完整对比（2016-2026，10只持仓）

| 阶段 | 年化收益 | 最大回撤 | 夏普 | 胜率 |
|---|---|---|---|---|
| 初版（含比特币矿企，无成本，无止损） | 62% | -60% | 1.25 | 52% |
| + 剔除MARA/MSTR/WULF | 63% | -57% | 1.28 | 52% |
| + 逐日真实市值过滤 + 交易成本（还没加止损） | 45% | -44% | 1.10 | 56% |
| **+ 止损组合（硬止损10% + 移动止损15%）** | **23%** | **-33%** | **0.85** | **44%** |
| 对照：单纯买入持有QQQ不动 | 20% | -35% | 0.93 | - |
| 对照：单纯买入持有SPY不动 | 15% | -34% | 0.88 | - |
| 对照：等权买入持有全部305只（不选股） | 31% | -44% | 1.14 | - |

**最诚实的结论**：修完全部三层问题之后，策略年化23%，只比单纯买QQQ的20%
略好，最大回撤(-33%)也和QQQ(-35%)基本在同一量级——这才是一个真实、有纪律
的动量策略应该长的样子，不是碾压市场的神奇公式。有个健康的细节：加了止损后
**胜率降到44%（低于一半）**，但平均赢的时候赚20.5%、平均亏的时候只亏9.3%
（赢的时候是亏的时候的2.2倍），62%的交易是被止损/移动止损止损离场的——这是
典型的"输小赢大"趋势跟随系统特征，不需要每笔判断都对，纪律执行止损就能整体
赚钱，这和用户"不追求精准、整体不亏钱"的目标是吻合的。

**这个对比表本身也有个提醒**：等权买入持有全部305只（完全不选股）年化31%，
比QQQ还高11个点——这11个点纯粹来自"股票池是用2026年信息挑出来的"，跟任何
选股策略都无关。动量选股+止损后的23%已经把这部分虚高基本挤掉了，剩下的
优势（23% vs 31%的"零技巧"基准，其实还更低！但换来了回撤从-44%降到-33%）
主要体现在**风险控制上**，不是"多赚钱"上。

### 拉长到2000-2026（覆盖互联网泡沫+2008金融危机）：个股止损单独扛不住系统性危机

上面所有结论都只测了2016-2026——历史上科技股最好的十年，完全没经历过真正
的系统性危机。把动量因子的价格数据（不含ROE/账面市值比/资金流，那几个因子
的SEC XBRL数据本身也拉不到这么早）拉到2000年（覆盖互联网泡沫）、外加2008
金融危机，重跑同样的策略（10只、21日再平衡、硬止损10%+移动止损15%、交易
成本0.1%），结果明显更严峻：

- **最大回撤从-33%恶化到-65%**，发生在**2009年3月16日**——正好是现实中
  标普500/纳指历史性见底的那个月，说明这个模拟没有明显失真。
- 分年看：2008年**-52.1%**，2002年（互联网泡沫余波）**-33.7%**，2022年
  **-35.5%**。
- **原因**：止损是个股层面的工具，危机时全市场一起跌，止损把你从一只跌的
  股票里踢出来，下一次调仓换进来的"当前动量最强"的股票往往也在跌，止损
  没有真正的安全港可去——个股止损管得了"这只股票自己出问题"，管不了
  "整个市场一起跌"。

### 加一层大盘趋势过滤（`backtest.build_regime_filter`），专门对付系统性风险

用最经典、几十年来的默认参数——**大盘指数（QQQ）收盘价是否高于自己的200日
均线**，高于＝risk-on正常持仓，跌破＝risk-off立即清仓空仓，直到重新升破。
**这不是调出来的参数，200日是这个方法本身的标准默认值，不是试了很多窗口
挑出的最佳值**。跟个股止损是互补关系，不是替代：止损管个股，regime过滤管
大盘整体。

| | 无regime过滤 | +200日均线regime过滤 |
|---|---|---|
| 年化收益(2000-2026) | 14.0% | **15.2%** |
| 最大回撤 | -64.8% | **-37.9%** |
| 夏普 | 0.61 | 0.73 |
| 2002年收益 | -33.7% | **-5.6%** |
| 2008年收益 | -52.1% | **-16.5%** |
| 2022年收益 | -35.5% | **-18.6%** |

三次历史危机全部大幅改善，且**收益不但没牺牲反而更高了**——这在回测里不算
常见（通常风控是拿收益换安全），值得留意但也不必过度惊讶：代价体现在别的
地方，比如2003年反弹年的收益从74.7%降到69.5%（均线确认新趋势需要时间，
会错过反弹最早的一段）。**这是目前整个项目里对"如何避免大幅亏损"这个问题
最直接、最有效的一个改进**，建议作为止损规则之外的标配，不是可选项。

### 参数敏感性检查：现在这组参数是稳健的，不是撞运气撞出来的

硬止损10%、移动止损15%、regime均线200日，都是行业惯例的标准默认值，不是
调出来的最优值，但还没验证过附近合理的参数变动会不会让结果差很多——如果
差很多，说明现在这组数字可能只是恰好组合在一起表现好（一种隐蔽的过拟合）；
如果差不多，说明这套逻辑本身是稳健的。用"一次只改一个参数、其余固定在
基准值"的方式测（不是穷举所有组合去挑最好的那组，那样做本身就是过拟合）：

| 变化 | 年化收益 | 最大回撤 | 夏普 |
|---|---|---|---|
| 基准（硬止损10%/移动止损15%/均线200日） | 15.2% | -37.9% | 0.73 |
| 硬止损→8% | 14.2% | -35.6% | 0.72 |
| 硬止损→12% | 15.4% | -38.2% | 0.73 |
| 移动止损→12% | 13.8% | -35.4% | 0.70 |
| 移动止损→18% | 15.6% | -39.2% | 0.73 |
| 均线窗口→150日 | 14.1% | -40.8% | 0.69 |
| 均线窗口→250日 | 16.3% | -37.5% | 0.77 |

所有变动的年化收益都落在13.8%-16.3%这个窄区间内（2.5个百分点的波动），
最大回撤都在-35%到-41%之间，没有任何一个变动让结果崩掉或者反转方向——
说明现在这组参数是稳健的，附近合理的数字都能给出质量相近的结果，不是
"恰好撞对"的运气。

## 踩过的坑（记录下来避免重复踩）

- **inf/-inf 污染因子分布**：第一版代码里，ROE = TTM净利润 / 股东权益，账面市值比 =
  股东权益 / 市值，都没有处理"股东权益 <= 0"的情况。扩大到244只股票后，跑出来
  `describe()` 里 ROE 均值直接变成 `-inf`——原因是部分科技公司常年大量回购股票，
  账面股东权益被打到接近0甚至为负，除法直接产生极端值/inf。修复方式：股东权益
  <=0 时因子直接置为空值（`np.nan`），这也是 Fama-French 价值因子的标准处理惯例
  （学术上直接剔除负账面权益公司），不是权宜之计。另外踩了一个 dtype 坑：一开始
  用 `pd.NA` 填充空值，导致列变成 `object` dtype，Alphalens 内部调用
  `np.isfinite()` 直接报错；改成 `float("nan")` 并显式 `.astype("float64")` 才解决。
- **壳公司/分拆重组的占位股数**：排查ROE反常方向时，winsorize后book_to_market依然
  出现28742倍的天文数字，且两只不相关股票（DXC、TripAdvisor）在同一天顶着完全
  相同的极端值——顺藤摸瓜发现DXC Technology 2017年从CSC/HPE分拆重组后，第一次
  XBRL申报的`EntityCommonStockSharesOutstanding`是占位数字"100"（真实股数2.85亿
  要等几个月后才更新），导致`market_cap≈100×股价≈0`，`book_to_market`炸出天文
  数字，还通过winsorize共享的分位数边界连累了同一天其他正常股票。修复：
  `edgar.py`的`MIN_PLAUSIBLE_SHARES_OUTSTANDING`过滤掉低于1万股这种明显是占位值
  的记录，当缺失处理，让`merge_asof`往前找上一个真实值。
- **用当前市值筛股票池、回溯全部历史价格的结构性风险**：动量因子一度出现188倍
  （18800%）126日收益的荒谬值，查到是QUBT（现在的"Quantum Computing Inc"，市值
  18亿美元够格进入用"当前市值"筛选的科技基础池）2018年那段历史——当时这个
  ticker/CIK对应的实体成交额中位数是**0**，多数交易日根本没有真实成交，价格只是
  挂单报价没有成交量。**不能用股价高低做门槛区分**：同期NVDA（复权调整后）股价
  也低至0.82美元，但成交额中位数2.86亿美元，是真实流动的交易；能区分"真实但
  便宜"和"挂单没成交"的是成交额，不是股价本身。修复：`validate.liquidity_mask`
  用过去21个交易日成交额中位数≥100万美元做门槛，剔除约4.6%的因子面板行。**这只
  是缓解，不是根治**——用"当前市值"筛出的股票池，本质上假设了"这只股票一直都是
  今天这个样子的公司"，对少数经历过分拆重组/改名/借壳的股票不成立，真正的根治
  需要做时点正确的历史成分股重建（point-in-time universe），工程量远超这轮精修
  范围，先记在这里。

## 已知限制 / 下一步

1. **部分外国私人发行人没有 ROE/价值因子数据**（ASML、TSM、VZ、T、FFIV、GWRE、NVT、
   QNT、SHAZ、LFTO 等）——它们走 20-F 年报或数据结构特殊，不按标准 10-Q/10-K 节奏
   报送 XBRL 数据，被 `factors.py` 自动跳过（打印 WARNING）。动量因子不受影响。
2. **还没做 3.2节的"主题贝塔"回归**（机制B验证）——这是 Phase 2 的内容，已完成，
   见 `phase2/README.md`。
3. **还没做 Phase 3 的严格验证**（走步前进、样本外冻结、Deflated Sharpe Ratio、
   交易成本）——现在的 IC/分层回测只是第8节验证阶梯的前两步。
4. **ROE因子的反常方向已排查**（见上方结果解读）：修了两个真实数据bug后异常依然
   存在，现在更倾向于认为是真实的经济现象（叙事驱动压过盈利质量），不是构造
   问题。如果还想继续深挖，行业中性化（按sector减去当天行业均值ROE）是一个还
   没试过的方向。
5. **没有做时点正确的历史成分股重建**（point-in-time universe）——用当前市值筛
   股票池、回溯全部历史价格，对少数经历过分拆重组/改名的股票（比如QUBT）会引入
   不属于"这家公司"的历史数据，流动性过滤只能缓解最极端的情况。
6. **价值因子（book_to_market）这次扩池后IC从0.008掉到接近0，已排查**：不是被
   新增小盘股拖累（第一次诊断结论有误，已改正），按逐日真实市值分段后大盘/
   小盘两段都是负的，这个因子在当前股票池/时段本身就不work，见上方"按市值
   分段检验"。
7. **资金流因子（insider_net_buy_pct）目前基本是噪音**（63日IC=0.0002）——P/S
   交易数量比例1089:53123，卖出压倒性地多，大概率是常规股权激励分散化减持
   （含Rule 10b5-1计划性卖出）稀释了信号。改进方向：解析Form 4 XML里的
   `aff10b5One`字段，把10b5-1计划性交易单独摘出来或者干脆排除，只保留真正
   自主决策的交易，这是目前insider.py还没做的一步。
8. **市值分段检验只覆盖有XBRL基本面数据的股票**——外国私人发行人（ASML/TSM/
   VZ/T等）没有`shares_outstanding`数据，算不出market_cap，会被市值分段
   检验排除（和已知限制#1是同一批股票，不是新问题）。
